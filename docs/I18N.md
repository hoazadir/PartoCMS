- RTL/LTR خودکار
- ترجمه خودکار محتوا (۷ Provider)
- کش ترجمه
- Language persistence

## سیستم i18n

### فایل‌ها

- admin/includes/i18n.php - کلاس I18n اصلی
- includes/content_i18n.php - Helper محتوا
- admin/includes/language_switcher.php - تغییر زبان
- admin/languages.php - مدیریت زبان‌ها
- admin/translations.php - مدیریت ترجمه‌ها

### توابع config.php

- getI18n() - نمونه I18n
- __t($key, $params, $default) - ترجمه
- __html_attrs() - lang + dir خودکار
- __dir() - جهت زبان فعلی

---

## توابع کلیدی

### getI18n()

$i18n = getI18n();

### __t() - ترجمه

echo __t('welcome', [], 'خوش آمدید');

### __html_attrs() - HTML Attributes

<html <?= __html_attrs() ?>>

خروجی: lang="fa" dir="rtl"

### __dir() - جهت

$direction = __dir(); // rtl یا ltr

### isRtl()

$i18n = getI18n();
if ($i18n->isRtl()) {
    // استفاده از Bootstrap RTL
}

## content_i18n

Helper مخصوص ترجمه محتوا.

### توابع

- getCurrentLanguageInfo() - اطلاعات کامل زبان
- getCurrentLanguageId() - ID زبان
- isDefaultLanguage() - آیا زبان پیش‌فرض است
- applyTranslationToPost($post) - ترجمه یک پست
- applyTranslationsToPosts($posts) - ترجمه گروهی
- applyTranslationToCategory($cat) - ترجمه دسته
- applyTranslationsToCategories($cats) - ترجمه گروهی
- translateAndCacheCategory($cat, $langId, $pdo)

### نمونه استفاده

$post = applyTranslationToPost($post);

$posts = applyTranslationsToPosts($posts);

$category = applyTranslationToCategory($category);

## ترجمه خودکار

### MultiTranslator v6.1

فایل: admin/includes/multi_translator.php

### ۷ Provider

| Provider | وضعیت | رایگان | نیاز به Key |
|----------|-------|--------|-------------|
| DeepL | فعال | 500K/ماه | ✅ |
| Microsoft | آماده | 2M/ماه | ❌ |
| Yandex | آماده | 1M | ❌ |
| Google | Rate Limit | نامحدود | ❌ |
| Lingva | Fail | - | ❌ |
| Libre | Fail | - | ❌ |
| MyMemory | فعال | 1000/روز | ❌ |

### ویژگی‌ها

- ترجمه موازی از همه provider ها
- Quality Scoring (0-100)
- تشخیص garbage
- tag_handling=html برای DeepL
- Cache با اعتبارسنجی مجدد
- Fallback خودکار

## Language Persistence

زبان فعلی به ترتیب اولویت از این منابع خوانده می‌شود:

1. URL parameter (set_lang)
2. Cookie (partocms_lang)
3. Session
4. I18n class
5. DB default

## RTL/LTR

### Bootstrap

لینک Bootstrap RTL:

bootstrap<?= getI18n()->isRtl() ? '.rtl' : '' ?>.min.css

### HTML Attrs

<html <?= __html_attrs() ?>>

### Body Class

<body class="<?= __body_class() ?>">

خروجی: dir-rtl یا dir-ltr

## نمونه استفاده

### ترجمه ساده

<h1><?= __t('site_title', [], 'عنوان سایت') ?></h1>

### ترجمه با پارامتر

<p><?= __t('hello_name', ['name' => 'Ali']) ?></p>

### بررسی RTL

<?php if (getI18n()->isRtl()): ?>
    <!-- RTL specific content -->
<?php endif; ?>

### تغییر زبان

<a href="?set_lang=en-US">English</a>
