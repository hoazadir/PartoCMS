## معرفی

PartoCMS یک سیستم مدیریت محتوای حرفه‌ای، ماژولار و چندزبانه است.

### نیازمندی‌های سیستم

- PHP >= 8.0
- MariaDB >= 10.4 یا MySQL >= 5.7
- وب‌سرور (Apache/Nginx)
- SSL Certificate (برای محیط تولید)

## نصب و راه‌اندازی

### مرحله ۱: دانلود

git clone https://github.com/hoazadir/PartoCMS.git
cd PartoCMS

### مرحله ۲: نصب وابستگی‌ها

composer install

### مرحله ۳: تنظیم config.php

cp config.example.php config.php

سپس config.php را ویرایش کنید و اطلاعات دیتابیس خود را وارد کنید.

### مرحله ۴: ایمپورت دیتابیس

mysql -u root -p grapesjs_cms < database/schema.sql

### مرحله ۵: اجرا

php -S 127.0.0.1:8080 -t .
